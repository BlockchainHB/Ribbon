Ribbon

A local scrolling window manager with a native Mac interface. Beta 0.1.0.

Start with Demo windows to try the strip. Choose Selected apps to explicitly select the applications Ribbon should manage. Pause restores original positions where applications accept them.

  • Control–Option + arrows: focus a window.
  • Add Shift to left/right arrows: reorder.
  • Control–Option–R: cycle width; F: full width; C: center.
  • Control–Option–]: stack. Add Shift to unstack.
  • Control–Option–Shift–T: switch a stack to tabs.
  • Control–Option + horizontal scroll: scroll the strip.
  • Control–Option–N: move a window to the next display, preserving its width proportion.
  • Control–Option–Q: stop the engine.

Ribbon requires Accessibility access. This local build is ad-hoc signed and is not notarized for public distribution. Rebuilding can require granting access again. No accounts, telemetry or network service are used.

The engine is based on Paneru, under the MIT license. The bundled third-party notices retain its attribution. The local fork adds application scoping, owned-helper lifetime and original-frame restoration.

Each display has an independent strip. Hardware results are recorded separately; physical unplug/reconnect, portrait arrangements, trackpad feel and sleep/wake remain manual verification items. Other window-management tools may share shortcuts.
