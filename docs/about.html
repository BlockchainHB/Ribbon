Your windows, side by side.

Ribbon keeps your Mac windows in a scrolling strip. It starts paused.

Start

  1. Allow Ribbon in System Settings → Privacy & Security → Accessibility.
  2. In Ribbon → Settings → General, turn on Window management.

Normal open app windows join automatically. Use Excluded Apps to leave particular applications alone. Pause from the menu bar to restore window positions where apps allow it.

Move and arrange

  • Control–Option + arrows focuses a window; add Shift to left/right to reorder.
  • Control–Option–R cycles widths. F toggles full width; C centers.
  • Control–Option–Tab opens Arrange Windows. Drag an icon to reorder or click to focus.
  • Right-click an icon to pair neighboring columns, ungroup them, or choose a ½–½, ⅓–⅔, or ⅔–⅓ arrangement.
  • Control–Option–] stacks vertically; add Shift to unstack.
  • Control–Option–N moves to the next display.
  • Control–Option–Q pauses and restores window positions.

Customize every assignment in Settings → Shortcuts. Pause before recording. Pairing shortcuts have no defaults.

Know the limits

Some apps enforce minimum sizes. Hidden windows may retain a small native edge. Pairs last for the current session. Physical multi-display pairing, mixed-scale transfers, reconnects, and sleep/wake are still being tested. Avoid using another window manager at the same time.

Requires Apple silicon and macOS 15 or later. Settings and recovery data stay local. No accounts or telemetry are used.
